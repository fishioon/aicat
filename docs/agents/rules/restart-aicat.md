# 重启 aicat

## 何时读

需要重启桌面端、网关，或替换应用构建产物时。

## 约束

- aicat 可能承载 ChatGPT 的网络连接。重启前先准备好构建产物、启动方式和检查命令，退出后立即重新启动，尽量缩短网络中断；不要在退出后再构建、排查或等待。
- 退出、重新启动和就绪检查必须由同一个本地脚本连续完成，不依赖退出后的 ChatGPT 网络或后续工具调用；脚本保存耗时和日志，恢复失败时立即回退可用版本。
- 重启仍遵循正常退出与系统代理恢复流程；启动后立即确认进程和网关监听恢复，失败时尽快恢复可用版本。

## 来源

迁移自 `AGENTS.md` 既有「重启 aicat」节，原始触发事件未留档；背景约束是应用承载 ChatGPT 网络连接，重启会造成断网窗口。

## 何时可删

aicat 不再承载用户网络代理，或网关与重启流程改为热更新、无需退出进程时。
