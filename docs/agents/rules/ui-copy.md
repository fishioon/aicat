# UI 文案

## 何时读

新增或修改界面文字（含 `t()` 调用、模板静态文案、按钮、标题、提示、无障碍属性）、语言切换行为，或清理翻译条目时。

## 约束

- 中文原文就是 key；`zh-Hans` 无需条目，`en` 必须补齐，漏配会让英文界面回退显示中文。
- 带 context 的调用要写 `context.原文` 形式的键。
- 提交前自查本次改动的中文字符串在 `ui/src/translations.json` 中都有对应 en 值；删除文案时同步清掉不再引用的条目。
- UI 前端只使用 `ui/src/translations.json`。`ui/src/generated/locales.ts` 是 mygo 从 Go catalog 生成的另一套后端 i18n，不要改它，也不要混用。
- 清理条目时以实际调用为准：Go catalog 里的符号（如 `Changes`）可能仍被业务代码使用，静态「零引用」检测有大量假阳性，不可据此批量删。

## 来源

2026-11-17 全量 UI 审查：8 个 `t()` 键缺英文映射，英文界面回退中文；清理过时条目时又发现「改写记录」（`Changes`）有 20 处 Go 业务调用，差点被误删。两套 i18n 独立是本次确认的架构事实。

## 何时可删

UI 前端翻译表改由生成链路自动维护、两套 i18n 合并，或项目不再提供英文界面时。
