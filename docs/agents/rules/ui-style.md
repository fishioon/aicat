# 样式

## 何时读

改动 CSS、组件内样式、主题色，或清理样式声明时。

## 约束

- 样式尽量简单、统一，优先保持原生表现，只在关键位置使用主题色。
- 能修改或合并原有规则时，不新增覆盖规则。
- 清理样式时只处理明显多余的声明，不扩大范围或重新设计界面。
- 图标尺寸、线宽、颜色与圆角以 `docs/design/design-language.md`、`docs/design/icon-standard.md` 为准。

## 来源

迁移自 `AGENTS.md` 既有条目，原始触发事件未留档；背景约束是界面重设计后避免覆盖规则累积与设计稿漂移。

## 何时可删

项目改用组件库或设计令牌体系并由其统一约束，或设计文档被新基线取代时。
