# Triage labels

工程 skills 使用五种 canonical triage role。下表定义它们在本仓库 GitHub Issues 中对应的实际标签。

| Canonical role | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，AFK agent 可以独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人类参与或实现 |
| `wontfix` | `wontfix` | 已决定不处理 |

当 skill 使用诸如“AFK-ready triage label”这样的角色描述时，使用本表对应的 GitHub label，不创建同义标签。
