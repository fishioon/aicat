# 图标规范

图标按用途分为导航图标和工具图标。导航图标表达稳定模块，工具图标表达页面内操作，两者分别维护，不跨用途复用。

## 导航图标

- 画布为 `20 × 20`，按 `20px` 显示，不通过 CSS 从 `16px` 缩放。
- 图形中心为 `(10, 10)`，主体视觉边界控制在 `3–17`；不同符号可按视觉重量单独微调。
- 基础视觉线宽为 `1 CSS px`，使用圆角端点和圆角连接；同一显示尺寸下保持一致。
- `1 CSS px` 在 `2x` 屏幕上对应 `2` 个设备像素；其他显示比例按实际尺寸计算，不额外乘系数。
- 圆角以 `1.5px` 和 `2px` 为主，不使用小于 `1px` 的内角。
- 只使用 `currentColor`，不内置颜色、阴影、渐变或背景。
- 图形应保留清晰开口和负空间，避免在 `20px` 下出现粘连或高密度短线。
- 未选中态使用 `--ink-2`；选中态使用 `--ink` 和 `--hover` 背景，图形本身不位移、不缩放。
- 模块图标使用稳定的对象或工具作为隐喻，不使用交换箭头、加号等动作符号表达模块入口。
- SVG 必须为装饰元素并设置 `aria-hidden="true"`；名称由外层按钮的 `aria-label` 提供。

当前模块图标为首页、消息、流量、扩展和设置。导航图标定义在 `ui/src/nav-icons.ts`，由 `ui/src/components/NavIcon.vue` 渲染；`docs/design/aicat-redesign.html` 保留同一组几何用于独立预览，修改时必须同步。

## 工具图标

- 画布为 `16 × 16`，主要按 `16px` 显示。
- 基础视觉线宽为 `1 CSS px`，与导航图标保持相同线条语言。
- 适用于搜索、复制、返回、关闭、状态等页面内操作。
- 工具图标定义在 `ui/src/icons.ts`，不直接用于左侧模块导航。

## 验收

- 导航图标按 `20px` 在 `1x` 和 `2x` 下检查轮廓、中心和视觉重量。
- 五个模块图标并排时，主体视觉尺寸接近，不出现明显过大、过小或过密。
- 同时检查隐喻：导航图标应表达模块本体，不应表达点击后发生的操作。
- 浅色与深色主题分别截图，选中态和未选中态都必须清晰。
- 使用后台 E2E 保存页面截图与报告，不以静态设计稿代替实际 WebView 结果。
