# 扩展与导航

用户在扩展中启停流量、Codex、微扑克、企业微信客户端与企业微信 BOT 扩展，流量在启用期间始终显示在默认导航中。扩展的边界与验收要求见 [扩展规范](../extension-standard.md)。代理始终运行；流量功能开关和临时暂停采集分别控制不同状态。

## Sub-features

- `extensions-browse`：搜索、展开或折叠已启用/推荐列表，按启用状态分组，未启用扩展统一归在推荐中，不区分是否安装，查看详情；主面板只保留一句简介、核心操作、必要配置和接入指引，不展示详情/功能标签页及重复介绍；列表只展示图标、名称与简介，启用状态由分组表达，不重复展示状态、分类和内置标签，分组数量使用普通文字；版本、发布者和来源收在默认折叠的“扩展信息”中。搜索匹配分类名称；`tag:channel` 按“消息渠道”类别筛选，可与关键词叠加，支持已启用、推荐和动态登记的渠道，语义不随界面语言变化。微扑克、企业微信 BOT 与企业微信客户端归为“消息渠道”，不增加分类筛选控件。
- `extensions-traffic`：启用或停用流量并保存，停用后隐藏入口、停止新采集。
- `extensions-codex`：启用或停用 Codex 扩展，见 [Codex 扩展](codex.md)。
- `extensions-wecom-local`：安装、配置与启停NPM企业微信客户端，增量消息保存到 Room，见[企业微信客户端](wecom-local.md)。
- `extensions-wecom`：配置、启停企业微信 BOT 并收发私聊文本，见[企业微信 BOT](wecom.md)。
- `extensions-packages`：可安装渠道按推荐版本安装，显示真实阶段、不定进度、已用时间及取消入口，失败可查看详情并重试，安装期间仍可浏览其他页面；停用后手动更新；更多菜单卸载并保留配置、凭据和业务数据。
- `extensions-settings`：已安装扩展的详情直接挂载自己的配置表单；“诊断”查看任务、消息及发送测试，保留扩展列表和当前选中项。全局设置只提供通用与代理。
- `extensions-open`：从详情打开流量或代理设置。
- `extensions-navigation`：流量作为默认导航入口，仅随扩展启停显示或隐藏；当前不显示“更多”。
- `extensions-placeholder`：社区扩展和已安装社区扩展显示真实占位状态。
- `extensions-icons`：Codex 与企业微信 BOT 使用随前端打包的官方应用图标，列表与详情一致；Codex 按应用主题切换浅深色资源，流量保留功能图标。

## How to get to it (user POV)

- 导航栏“扩展” → 已启用 → 流量 → 启用/停用；齿轮菜单里是打开流量、代理设置、复制扩展标识符。
- 企业微信 BOT 安装后在详情中配置并验证账号；详情 → 诊断，诊断 → 配置返回详情。前进/后退恢复扩展、诊断与全局设置的页面归属和所选扩展。
- 导航栏“流量” → 打开流量页；默认导航不提供取消固定，当前不显示“更多”。
- 扩展侧边栏搜索框筛选条目；已启用列表展示当前启用的扩展；推荐列表展示其余扩展，包括已安装但未启用的扩展。安装完成后仍在推荐列表，配置鉴权验证通过并启用后才移入已启用列表，停用后返回推荐列表。列表通过已启用或推荐分组表达状态，安装操作保留在详情中。
- 流量扩展默认启用；采集默认暂停，在流量页点击“开始采集”后才记录新请求。
- 启动进入主页；流量功能停用时导航和前进后退都跳过流量页，扩展与设置仍可使用。

## Driving it with Playwright

Preconditions:

- **功能分类。** 独立后台运行 `node e2e/extension-categories.cjs bin/aicat-e2e`，验证按启用状态分组、启停后移动与选中项保留、数量和折叠、空列表、刷新恢复、列表和标题不展示标签与重复状态、默认折叠技术信息并可展开、无详情/功能标签页、Codex 接入配置仍可用、中英文分类搜索及浅深色和 1180/860 宽度，保存报告、日志和截图；不安装或启用渠道。

- **品牌图标。** 独立后台运行 `node e2e/extension-icons.cjs bin/aicat-e2e`，验证列表和详情的官方图标、本地加载、浅深色切换和 36/64px 容器，保存截图与报告；不启用渠道或访问真实凭据。资源来源见各扩展 assets/README.md。

- 本次验收实例流量已启用、正在采集，已有一条记录，已记录当前域名。

- **默认不采集。** 可独立运行 `node e2e/traffic-default.cjs bin/aicat-e2e build/traffic-default-<run>`。从全新 Home 启动，流量扩展启用且导航入口可见，打开流量页显示尚未开始采集；代理请求成功但 `/api/traffic` 为空。点击“开始采集”后记录新请求；扩展启停保留本次会话的采集状态，重启后默认回到暂停。另核对缺失、空/null 配置、显式扩展开关与 `traffic.recording`，保留截图和报告。
- **找到扩展。** 点击 `#nav-extensions`，在 `#extension-search` 输入 `traffic`，点击 `#extension-traffic`；详情显示内置流量和 `#feature-traffic[aria-checked="true"]`。输入不匹配的词后条目消失，清空恢复。
- **关闭。** 点击 `#feature-traffic`（文字由“停用”变为“启用”）；`#nav-traffic` 消失，详情出现停用说明，齿轮菜单 `#extension-menu` 里的“打开流量”禁用。调用 `send('/feature-disabled')`，上游仍返回正常结果，`api()` 中没有这条新记录，但原记录仍存在。
- **恢复。** 再点 `#feature-traffic`，在齿轮菜单点击“打开流量”，发送 `/feature-resumed`，列表与 API 出现新记录。先在流量页点 `#recording` 暂停，再关闭和开启功能，回到流量页应仍暂停；手动继续后才采集新请求。
- **默认导航。** 独立后台运行 `node e2e/navigation.cjs bin/aicat-e2e build/navigation-<run>`。验证主页、消息、流量、扩展与设置入口及当前页面高亮；没有“更多”和导航固定操作；已有 `navigation.pinned` 为空或不含流量时，流量仍显示。停用流量后隐藏入口、历史跳过流量页，重启保持停用，再启用恢复；保存浅深色与不同宽度截图、配置、日志和报告。
- **入口与占位。** 推荐列表的企业微信条目提供安装入口；点击安装后仍保留在推荐列表，启用后移入已启用列表。未安装条目没有配置入口，安装后可配置，验证通过才允许启用。
- **重启。** 保存流量关闭状态后重启同一 Home，启动应进入主页且导航栏没有流量；再启用并确认入口恢复。检查 `aicat.yaml` 中 `extensions.traffic.enabled` 与界面一致。

## Gotchas

- `extensions.traffic.enabled` 缺省开启，控制入口和功能可用性；`traffic.recording` 缺省 `false`，控制启动时是否采集。显式配置优先。
- 手动开始/暂停仅作用于本次运行，重启按 `traffic.recording` 初始化（默认暂停）；功能开关持久化。重新启用功能保留本次会话之前的暂停状态。
- 关闭流量不关闭代理或只读 API；现有记录仍受容量淘汰与清空影响。
- 默认导航不受 `navigation.pinned` 影响。流量扩展停用期间隐藏入口，重新启用后恢复；当前没有额外的低频功能入口，“更多”隐藏。
- 当前内置流量与Codex；推荐提供企业微信BOT、客户端与微扑克NPM渠道，可按固定版本安装、配置并启用。扩展列表也支持登记第三方aicat API消息渠道包，同包可指定新版本更新。Room处理与模型配置在消息页面。

## 配置与导航定向验收

运行 `node e2e/settings-navigation.cjs bin/aicat-e2e build/settings-navigation-<run>`。使用隔离 Home、headless Chromium 与隐藏的验收应用，验证通用与代理设置、未安装扩展无配置表单、已安装扩展直接配置并写入 aicat.yaml、诊断按钮与菜单、返回配置、跨扩展和全局设置的前进/后退。浅深色及 1180/860 宽度截图、命令、二进制摘要、报告与应用日志保存在输出目录；不覆盖原生窗口与系统授权。

包生命周期使用 `node e2e/extension-lifecycle.cjs bin/aicat-e2e build/extension-lifecycle-<run>` 定向验收，覆盖慢下载反馈、取消与重试、导航及跨页面状态恢复、中英文与浅深色、失败与中断恢复、版本切换和卸载保留数据，详见[包管理](../extension-packages-design.md)。
